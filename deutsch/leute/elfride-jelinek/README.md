"Die Schule hat die Macht, alles zu überprüfen und einen dann gleich weiter zu prüfen. Eine harte Prüfung. Das ist mir noch heute ein unerträglicher Gedanke, daß jemand soviel Macht haben soll, von einem anderen etwas, ausgerechnet ein Können, das den Menschen immer so unsanft aus seiner Gemütlichkeit reißt, zu verlangen."
